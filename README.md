## Sobre mim

Construo software porque é a ferramenta mais direta que conheço pra transformar uma ideia em algo que existe no mundo.  
Antes de código, passei mais de uma década resolvendo problema real — na hora, sem manual. Isso moldou a forma como penso sistemas: pouca paciência pra solução bonita que não resolve nada e preferência por arquitetura que se sustenta sob pressão.

Tudo o que está público aqui é open source.  
Clona, lê, refatora, manda PR. Código existe pra ser usado, não pra ficar trancado.

## Projetos

### [ReqGuard](https://github.com/ThomasRhoden/ReqGuard)
Plataforma de gestão do ciclo de vida de requisitos de software, do levantamento com stakeholders até o backlog priorizado. Orquestrada por 6 agentes de IA, com rastreabilidade completa e conformidade LGPD integrada em cada etapa do fluxo.

`Python` `FastAPI` `PostgreSQL` `SQLAlchemy` `Pydantic` `Alembic`

### [Trading Bias Dashboard](https://github.com/ThomasRhoden/trading-bias-dashboard)
Painel macroeconômico em Python (Flask + MVC) para leitura de mercado pré-abertura. Consolida dados globais e calcula um viés estatístico direcional com base em ativos-chave (SPY, USO, EWZ, VALE3).

`Python` `Flask` `Bootstrap` `tradingview_ta`

### [Notifiq](https://github.com/ThomasRhoden/notifiq)
App mobile de gerenciamento inteligente de notificações pessoais. Criação e agendamento de alertas com personalização visual, persistência local e arquitetura limpa.

`Dart` `Flutter`
